# seaquel-runtime

Moved from the root `CLAUDE.md`, which has the overview and the crate map. "Above" and "below" may point at sections that now live in another `CLAUDE.md`.

- `seaquel-runtime` — `MaybeSend`, `BoxStream`, `Executor` (`spawn`, `sleep`, `unix_time`, `monotonic`; `TokioExecutor`, `WasmExecutor` over `performance.now()`), `#[seaquel_runtime::async_trait]`. The `acl` feature (turned on by `seaquel-http`'s `release-asset` and the engine crate's `remote`; `windows-sys`, Windows only) is the one Windows ACL rule the helper's install and its start share, kept here because the engine crate may depend only on pure crates: a pure judge over `Security { owner, dacl, protected }` and, on Windows, `inspect`, `make_private` and `acl::Node`, which open each path with `FILE_FLAG_OPEN_REPARSE_POINT` so a link is described, never followed. Below `<identifier>` an entry that applies and grants write, append, delete-child, `DELETE`, `WRITE_DAC`, `WRITE_OWNER`, `GENERIC_WRITE` or `GENERIC_ALL` to anyone but the user, SYSTEM or Administrators is refused (deny entries neither refuse nor excuse; inherit-only entries are the children's); at `<identifier>` only the rights that replace or rename (`rights::REPLACE`: delete-child, `DELETE`, `WRITE_DAC`, `WRITE_OWNER`, `GENERIC_ALL`) count, so others may add files there. The owner must be the user, SYSTEM or Administrators; a NULL DACL is refused; only name-surrogate reparse points are links (WOF, dedup and cloud placeholders pass). The Win32 half runs only in CI's Windows leg. Core crates must build for wasm32: no `tokio::spawn`, `Instant` or `SystemTime` (enforced by `crates/clippy.toml`).
