# seaquel-ai

Moved from the root `CLAUDE.md`, which has the overview and the crate map. "Above" and "below" may point at sections that now live in another `CLAUDE.md`.

- `seaquel-ai` — the AI domain crate (phase 6), reached as `seaquel_core::ai`; it builds for wasm32 (CI's "seaquel-ai builds for wasm32" step) with no tokio, reqwest, clock or file system, and `check-crate-deps.mjs` holds it to `WASM_DOMAIN`: pure crates and `seaquel-workspace` only. `http` (the `HttpClient` trait, `send` with a method, `Redacted` headers, `HttpError::code()`), `sse` (a byte-level parser, about 32 MiB held at most), `wire/{anthropic,openai}` (request bodies as today's TypeScript sent them, `round_request`/`generate_request`/`models_request`, `Decoder`, `check_status_with`; Anthropic's direct-access header only from the browser; budgets per round: 64 calls, 16 MiB of arguments and of text, 256-byte names; 429 is `RATE_LIMITED`, other non-2xx `PROVIDER_ERROR`; error text cut at 1 KiB with the key redacted, and only the status and error type in `Debug`/`Display`), `tools` (the registry: `Tool`, `definitions`, `prepare`, `parse`, `read_only_check`, the `mcp` argument structs rmcp lists, `render` and `format`, MCP's cell rendering moved here), `prompt` (`system`, `schema_context`, `mentions`, `history`, `push_user`), `limits` (`AiLimits`, the budgets above, `QuerySpec`) and `sharing`. The `testing` feature (native) has `MockProvider`, `scripts`, `LoopbackOnly` and `TEST_KEY`. `tests/fixtures/tool-schemas.json` freezes every tool's schema for both profiles; MCP's `tests/tool_schemas.rs` and the registry both compare against it.
